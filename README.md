# Backyard Bird Log

Birds identified from a rooftop camera microphone in the Pacific Northwest, with time of day and weather.
Live page: https://herzog303-commits.github.io/backyard-birds/

- Identifications: [BirdNET-Analyzer](https://github.com/kahst/BirdNET-Analyzer), scoring five-minute clips as they are recorded.
- Weather: nearest hourly Sea-Tac observation.
- `data/` is regenerated and pushed automatically. No audio or location is published.
